# Besto

Маркетплейс в стиле iOS: сайт и Android-приложение с админ-панелью.

- `web/` — сайт (`index.html`), данные хранятся в Supabase.
- `android/` — Android-приложение, внутри работает тот же сайт.
- После каждого push в ветку `besto` GitHub Actions собирает `Besto.apk` (раздел **Releases**, релизы `besto-N`).

## Админка
Профиль → «Войти или зарегистрироваться» → «Стать администратором магазина» (кнопка есть только пока админа нет).
В «Админ-панели» меняются логотип, название, цвета, баннеры, товары с фото, категории, тексты и статусы заказов.
